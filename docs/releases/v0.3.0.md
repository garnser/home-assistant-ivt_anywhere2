Adds optional local iCom readings and configurable heat/COP estimates to the integration.

- Enable local polling and the model through **Configure**. Both remain off by default for existing cloud-only installations.
- Reuse local credentials from a matching Bosch integration entry. Configure the gateway address, operating sensors and manufacturer rating instead of editing Python files.
- Keep local polling and model startup independent of cloud failures.
- Expose rolling estimates, covered-month subtotals and explicitly labelled month projections. Optional calibration requires complete, stable daily readings and chronological validation.
- Retain valid zero electricity readings; flag possible coarse reporting instead of adding guessed consumption. Model estimates never become recorded electricity or their own calibration labels.
- Include setup documentation, redacted diagnostics, and 153 calculation/runtime checks.

Update through HACS and restart Home Assistant. Keep your existing IVT entry and Energy-dashboard electricity source. Enable the optional features only after selecting suitable sensors and verifying your pump's reference specification; the supplied GEO 512C defaults are not universal.

Back up any manually customised integration before updating. Experimental installations with local-only model code need their options, cached model history and any changed entity identities migrated before replacement. See `docs/heat-model.md` for assumptions and limits. These estimates are not independently validated heat-meter measurements.
